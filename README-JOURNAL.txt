MODERN DHARMA JOURNAL - YAML IMPLEMENTATION

Upload all files and folders to the repository root.

Content source of truth:
  _data/journal.yml

To update the Journal:
1. Edit _data/journal.yml.
2. Add, remove, reorder, or revise an entry.
3. Use category: inquiry, principle, observation, or framework.
4. Commit and push. GitHub Pages/Jekyll rebuilds /journal/ automatically.

Important:
- YAML uses spaces, not tabs.
- Keep indentation consistent.
- Direct file:// preview cannot process Liquid. Test after GitHub Pages deploys, or run Jekyll locally.
